# Real-Time Object Detection & Tracking - CodeAlpha

This project is part of my **Artificial Intelligence Internship at CodeAlpha**. It uses the state-of-the-art **YOLOv8** model to detect and track objects in real-time via a webcam.

## 🚀 Key Features
- **Real-Time Detection:** Identifies objects like persons, laptops, and mobile phones instantly.
- **Object Tracking:** Assigns unique IDs to objects to track them across frames.
- **YOLOv8 Architecture:** Utilizes the Nano version for high speed and efficiency on standard hardware.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Computer Vision:** OpenCV
- **Deep Learning Model:** Ultralytics YOLOv8
